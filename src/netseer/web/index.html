            Compare surveys

            Pick a baseline, then the surveys to check against it. Each capture has its own time window, so a morning baseline can be compared with an afternoon survey. You get a new map for each one, with what changed shaded:

            • Left a network, or no longer seen
            • Joined a network, or new
            • Other changes: moved networks, a new random MAC, a possible rogue access point…

            Disconnect devices

            Removes the links between them from this map. Both devices stay where they are, and you can undo it.

            Add to a subnet or VLAN

            Put a device in a network the capture didn't place it in. It's marked as added by you.

            Vulnerability data

            Each device's Security details match the software versions it revealed against known vulnerabilities, with no internet needed: the data comes with NetSeer. Each vulnerability shows its severity, and its EPSS score: FIRST's estimate of the chance it's exploited in the wild in the next 30 days.

            …

            Update database downloads the latest data from NVD (the U.S. National Vulnerability Database), FIRST (EPSS scores), and CISA (known exploited vulnerabilities), in a few minutes. It sends only the names of the products NetSeer knows, such as OpenSSH; nothing about you or your maps. Without updating, the data is as current as your version of NetSeer.

            This online copy uses the vulnerability data that came with its version. Installed copies can update it.

              Versions

              1. Click Check for updates to list the versions on GitHub.

              Going back to an older version works the same as installing it, and your maps stay where they are. Back them up first under Your data, just in case.

              This online copy updates itself whenever NetSeer changes on GitHub, so it always runs the newest version. Reload the page to pick up a change made while you had it open.

              NetSeer can keep itself up to date: it checks for a new version and downloads it in the background, then asks before it restarts to install.
